# 粘贴 · 统一标记 · 取消标记 · 按树用例 · 布局重排

## Report

## [S1] Problem
镜像内复制粘贴无效；标记入口分散；识别框右键无法取消标记，也无法一键清空/批量切换；已入树的元素仍出现在「自动发现元素」里；生成用例未严格以树上已识别功能点为准；交互元素表占中栏，浏览器镜像偏小。

## [S2] Design

### 2.1 复制粘贴
- IME 代理支持 `paste` 写入焦点（已具备）；补齐 `copy`：选中页面文本时宿主 Ctrl+C 从页面选区复制（Playwright `page.evaluate` 读 selection）。
- Ctrl+V 优先走代理 `paste` 事件；镜像 `keydown` 不再吞 Ctrl+C/V/X。

### 2.2 统一「标记为…」
- 元素表、识别框右键、批量「挂到当前节点」共用同一弹窗：类型=模块/一级/二级/三级/功能点。
- 快捷：识别框右键菜单「标记为…」「取消标记」「批量取消本页标记」。

### 2.3 取消/批量标记
- 右键识别框：取消该标记（含树 element_ids 摘除）。
- 「一键取消本页标记」清空 state.marked 与本页元素 marked。
- **Ctrl+点击识别框**：切换标记（取消↔恢复）。
- 自动发现元素时**过滤** selector 已挂在任意树节点 element_ids 的元素；手动「标记为…」仍可加回。

### 2.4 按树生成用例
- 「生成用例」仅遍历树中 `point/case` 节点（含已挂 element），忽略仅存在于已标列表、未入树的素材。

### 2.5 布局（图3/4）
```
┌──────────────┬────────────────────────────┬──────────┐
│ 功能点树     │ 浏览器壳 + 实时镜像（更大）│ 判定     │
│ 交互元素(下) │                            │ 截图库   │
│              │                            │ 已标/用例│
└──────────────┴────────────────────────────┴──────────┘
```
- 交互元素表移至左栏下部；中栏整列给浏览器；右栏不变。

## [S3] Out of Scope
- 系统级剪贴板权限提权；拖拽跨窗口。
